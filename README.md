# 得点管理システム（Team Project）

専門学校の授業課題として、提示された企画書・ユースケース図・シーケンス図・クラス図・テーブル設計書・画面設計書をもとに、4名チームで約1か月かけて開発した Web アプリケーションです。  
学生・クラス・得点情報を管理し、登録・更新・削除・検索を行うことができます。

## 開発環境
- 言語：Java（JSP / Servlet）
- DB：**H2 Database（H2 Console）**
  - ドライバクラス：`org.h2.Driver`
  - JDBC URL：`jdbc:h2:~/exam`
  - ユーザー名：`sa`
  - パスワード：なし
- IDE：Eclipse
- 構成：MVC（Servlet / DAO / Bean / JSP）
- バージョン管理：GitHub

## 担当範囲（自分が実装した部分）
### 学生管理機能（メイン担当）
- 一覧表示・新規登録・変更機能の DAO / Bean / Action を実装  
- JSP を用いた画面作成とフォームバリデーション  
- Servlet・DAO・Bean を連携させた MVC 構造の構築 

### 追加機能：クラス管理機能
- 設計書にない機能をチームで相談し、要件定義から実装まで担当  
- クラス登録・一覧・更新・削除機能を新規作成  
- 学生管理との連携を考慮したテーブル設計・画面遷移を実装  

##  チーム開発体制
- WBS を用いてタスクを細分化し、役割分担を明確化  
- GitHub によるソース管理・レビューを実施  
- 週次ミーティングで進捗共有・課題解決を実施  

## AI 活用箇所（明示）
- **エラーコードの特定・原因調査**
- **JSP関連のレイアウト調整**（画面構成・includeパス修正など）  

## 注意事項
- チーム開発のため、担当箇所を明記しています  
- 一部のエラー調査・レイアウト修正に生成 AI を使用しています
